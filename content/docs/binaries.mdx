## Design Systems 

## Binaries 

What are digital systems and how do we build them? How do we design processors? Computer technology is based on digital electronic circuits. All the data must be encoded in 0s and 1s. Computer technology is based on electronic circuits that process all of this information. 

We start off with data types. Data types include numbers, characters, sounds, pictures, videos. 

What is the binary encoding system? Some common ones include: 
* decimal system: uses 10 digits starting from 0 and ending at 9. It is position system. 
* binary system: uses 2 digits
* hexadecimal system: uses 16 digits 

How can we represent numbers? We are trying to find the binary systems.
